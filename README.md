# МастерСип — интерактивный макет

Финальная редакция: **23 октября 2026 года · 20261023-final-v9**.

Это статическая адаптивная версия сайта. Реальная отправка и серверное хранение контактов не подключены: при попытке отправки показывается сообщение о недоступности и ссылка на почту. Рабочий WordPress не изменяется. Индексация HTML-страниц закрыта через `noindex`.

## Новый репозиторий GitHub

Веб-загрузчик GitHub принимает до 100 файлов за раз. В архиве `mastersip-github-upload-v9.zip` файлы разделены на папки `01`, `02`, `03`, `04`: загружайте **содержимое каждой папки по очереди в корень репозитория**, нажимая Commit changes после каждой загрузки. Сами папки 01–04 в репозиторий не добавляйте. После всех четырёх загрузок включите Pages по инструкции ниже. На Mac сочетание Command + Shift + . показывает скрытые файлы `.nojekyll` и `.gitignore`.

1. Распакуйте архив.
2. Загрузите **содержимое архива в корень нового репозитория**. Файл `index.html` должен находиться сразу в корне рядом с `app.js`, `style.css` и папкой `assets`.
3. Сохраните файл `.nojekyll`. Не загружайте один ZIP вместо распакованных файлов; дополнительная папка вокруг сайта не нужна.
4. В **Settings → Pages** выберите **Deploy from a branch → main → /(root)** и сохраните. Если ветка называется иначе, выберите её.
5. После публикации откройте адрес, который покажет GitHub Pages. Он обычно имеет вид `https://имя.github.io/репозиторий/`.

Сборщик, npm и отдельный workflow не нужны. Для большого количества файлов удобнее использовать GitHub Desktop или Git. Сайт поддерживает размещение в подпапке репозитория.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Локальный запуск

Из папки сайта:

```sh
python3 -m http.server 8766
```

Откройте `http://127.0.0.1:8766/`. Открытие через `file://` не поддерживается.

## Что входит

- 10 содержательных страниц: главная, проекты, технология СИП с разделом о фундаменте, о компании, контакты, семейная ипотека, материалы и документы, политика конфиденциальности, согласие на обработку данных, реквизиты.
- Единый каталог из 112 проектов в окнах, поиск и фильтры площади и этажности. Разделения на все и построенные проекты нет. Каждый проект открывается с визуализацией; исходник доступен переключателем.
- Прямые ссылки на окна вида `proekty/#r-075`.
- Вопросы и ответы — раздел `/#faq` главной, доступный из меню и подвала. Раздел отзывов временно убран.
- Кнопка «Обсудить проект» на первом экране открывает прямую форму; «Рассчитать стоимость дома» — квиз.
- Два обязательных пустых флажка: ознакомление с политикой и отдельное согласие. Юридическое окно сохраняет форму под ним.
- Шаблоны писем команде и посетителю в `mail-templates.js` для подключения серверной доставки. Файлы с вымышленными примерами заявок исключены из публичного сайта.
- Пять документов / восемь сканов: изображения загружаются по нажатию. Сканы сохранены без изменения текста, печатей и дат. Архивные статусы обозначены.
- Единая типографика на всех страницах и устройствах: Georgia для заголовков и названий проектов, Arial для текста, меню и элементов управления. Стопки шрифтов заданы общими переменными CSS.
- Единая тёплая палитра на телефоне, планшете и компьютере. На десктопе доступна нейтральная панель «Компьютер / Планшет / Телефон»: она меняет фактическую ширину сайта внутри iframe. На обычном телефоне сайт открывается непосредственно.

`portfolio/`, `faq/`, `otzyvy/`, `cookies/`, `svajnyj-fundament/` — только технические переходы со старых адресов. Они не являются отдельными содержательными страницами. Перечни: `routes.json` и `redirects.json`.

`project-image-map.csv` сопоставляет проект с исходной записью. `redirect-plan.csv` — предложение будущих перенаправлений исходного WordPress; этот CSV не включает их автоматически на GitHub Pages.

## Ограничения макета

Телефон и ссылки Telegram/MAX не указаны, поэтому эти способы связи скрыты. Действующая ссылка на почту: `print.st.avtor@mail.ru`.

Формы не отправляют данные. В браузере хранится только выбор cookie, а при разрешении — локальный демонстрационный счётчик. Внешней аналитики и встроенных карт нет. Публикация на GitHub Pages отдельно подразумевает техническое журналирование посещений платформой, что отражено в политике.

Презентационные изображения обозначены как визуализации. Параметры, комплектация, условия подарочного проекта и гарантии должны соответствовать будущему договору.
