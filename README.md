# МастерСип — интерактивный макет

Финальная редакция: **25 октября 2026 года · 20261025-messengers**.

Это статическая адаптивная версия сайта. Реальная отправка и серверное хранение контактов не подключены: при попытке отправки показывается сообщение о недоступности и ссылка на почту с уже заполненными темой и данными обращения. Рабочий WordPress не изменяется. Индексация HTML-страниц закрыта через `noindex`.

## Обновление репозитория GitHub

Макет опубликован в `lysokon995-cmd/mastersipms`, ветка `main`. Последующие изменения обновляют существующий сайт без повторной загрузки неизменившихся файлов.

Текущий `mastersip-github-upload.zip` содержит только 16 новых и изменённых файлов относительно версии `20261024-project-contact` (коммит `f749c6f`). Все файлы помещаются в одну часть `01`, ниже ограничения в 100 файлов.

1. Распакуйте архив. В корне существующего репозитория выберите **Add file → Upload files**.
2. Откройте `01` в Finder и перетащите **всё содержимое**, а не саму папку `01`. Папка `assets` объединится с существующей по тем же путям.
3. Нажмите **Commit changes** в `main` и дождитесь успешной публикации в **Actions**.

Папку `01`, ZIP и файл инструкции в репозиторий не загружайте. Существующие файлы с теми же путями обновляются, новые добавляются. Полный сайт для переноса находится в `mastersip-prototype`; архив обновления не предназначен для пустого репозитория.

## Локальный запуск

Из папки сайта:

```sh
python3 -m http.server 8766
```

Откройте `http://127.0.0.1:8766/`. Открытие через `file://` не поддерживается.

## Что входит

- 10 содержательных страниц: главная, проекты, технология СИП с разделом о фундаменте, о компании, контакты, семейная ипотека, материалы и документы, политика конфиденциальности, согласие на обработку данных, реквизиты.
- Единый каталог из 112 проектов в окнах, поиск и фильтры площади и этажности. Добавлена категория «До 60 м²» с 10 проектами, включая 60 м²; она также доступна в подборе дома. Разделения на все и построенные проекты нет. Каждый проект открывается с визуализацией, за ней доступны его планировки. Изображения можно открыть крупнее. Описания и комплектации «Эконом» и «Премиум» соответствуют исходной карточке проекта.
- Прямые ссылки на окна вида `proekty/#r-075`.
- Вопросы и ответы — раздел `/#faq` главной, доступный из меню и подвала. Раздел отзывов временно убран.
- Четыре преимущества на первом экране: на компьютере и планшете — компактная сетка 2×2 внутри текстовой колонки перед кнопкой, без внешней рамки; на телефоне — светлая сетка 2×2 перед подбором проекта. Семейная ипотека идёт четвёртой. На телефоне сохранена фотография высотой 220 px без сжатия по высоте окна. На компьютере и планшете левые края заголовка, текста, преимуществ и кнопки совпадают с общей сеткой контента. Над каждым преимуществом — тонкая горизонтальная линия; фотография справа доходит до края экрана и не перекрывается текстом.
- Блок «Технология вашего комфорта: почему именно СИП?» расположен после hero (на телефоне — после подбора дома) и перед ипотекой. На компьютере и планшете — заголовок слева и четыре пункта справа; на телефоне — вертикальный список. Ссылка ведёт непосредственно к полным объяснениям на странице технологии: `tehnologiya-sip/#sip-benefits`.
- В разделе технологии оставлен выбранный короткий текст: четыре исходных заголовка и по одной фразе под каждым. Переключатели редакций удалены. Полные объяснения клиента сохранены на странице технологии.
- Ипотечная плашка содержит заголовок «Семейная ипотека для вашего дома», предложение «Первый разбор вашей ситуации — бесплатно» и кнопку на подробную страницу семейной ипотеки. На этой странице размещён полный клиентский текст об ипотечном сопровождении без служебных пометок.
- Все кнопки расчёта и обсуждения открывают прямую форму связи. В карточке дома автоматически подставляются проект и выбранная комплектация. Номер проекта и комплектация указаны в теме письма; параметры дома и ссылка на карточку — отдельным блоком внутри письма. Общие формы не подхватывают ранее просмотренный дом. Квиз полностью удалён.
- Два обязательных пустых флажка: ознакомление с политикой и отдельное согласие. Юридическое окно сохраняет форму под ним.
- Шаблоны писем команде и посетителю в `mail-templates.js` для подключения серверной доставки. Файлы с вымышленными примерами заявок исключены из публичного сайта.
- Пять документов / восемь сканов: изображения загружаются по нажатию. Сканы сохранены без изменения текста, печатей и дат. Архивные статусы обозначены.
- Единая типографика на всех страницах и устройствах: Georgia для заголовков и названий проектов, Arial для текста, меню и элементов управления. Стопки шрифтов заданы общими переменными CSS.
- Единая тёплая палитра на телефоне, планшете и компьютере. На десктопе доступна нейтральная панель «Компьютер / Планшет / Телефон»: она меняет фактическую ширину сайта внутри iframe. На обычном телефоне сайт открывается непосредственно.
- Основные изображения домов не повторяются: hero главной — `editorial-house.webp`, блок «Строим дома как для себя» на главной — новый `garden-house.webp`, страница компании — `catalog-house.webp`, семейная ипотека — `mortgage-portrait.webp`. Адаптивные версии одного hero используют один файл. Изображения каталога не менялись.

`portfolio/`, `faq/`, `otzyvy/`, `cookies/`, `svajnyj-fundament/` — только технические переходы со старых адресов. Они не являются отдельными содержательными страницами. Перечни: `routes.json` и `redirects.json`.

`project-image-map.csv` сопоставляет проект с исходной записью. `redirect-plan.csv` — предложение будущих перенаправлений исходного WordPress; этот CSV не включает их автоматически на GitHub Pages.
