# Четыре концепции главной страницы Областной санитарной службы

Просмотр: https://lysokon995-cmd.github.io/mastersipms/

1. **Выездная служба** — жёлтый и графитовый, крупная узкая типографика.
2. **Забота о доме** — прежний зелёный вариант с фотографиями дома и участка.
3. **Точный подход** — прежний жёлтый вариант.
4. **Ясный сервис** — прежний синий вариант.

Выбор варианта и устройства сохраняется в параметрах URL. Есть режимы компьютера, планшета и телефона, поиск по 61 услуге, выбор прайса, документы и контактная панель. Публикация — статический GitHub Pages из корня ветки main, сборщик не нужен.

Это демонстрационные макеты главной страницы: формы не отправляют данные. Юридические материалы требуют утверждения перед реальным использованием. Фото — иллюстрации; происхождение и лицензии находятся в assets.

Предыдущий сайт Master SIP сохранён в ветке archive/master-sip-before-oblsan-20261027 и в истории Git.

Услуги и цены подняты к началу главной. Восемь направлений с прямым выбором конкретной задачи; полный каталог сохранён.
